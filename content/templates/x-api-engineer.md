## What it does

Takes a developer from zero to a working demo on the X API. It surveys the Developer Exhibit, works through the documentation, then builds whichever app you choose and gets you through setting up console keys along the way. Once the build is done it shows the result running, so the whole path stays visible end to end. It runs when you ask it to, rather than on a timer.
